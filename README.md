# Learning

A personal learning workspace containing practice projects and study material across multiple languages and topics.

## Contents

- **Agentic_AI_Langraph/** — Python work on agentic AI with LangChain and LangGraph, plus small practice scripts (e.g. a Rock-Paper-Scissors game).
- **CPP/** — C++ practice, including the A2Z sheet (basic maths, pattern problems) and assorted mini-projects.
- **Sudoku/** — A C++ Sudoku solver with validator and tests.
- **TestNConcepts/** — Small C/C++ experiments and concept tests.

## Notes

Build directories, compiled binaries, Python caches, and virtual environments are excluded via `.gitignore`.
